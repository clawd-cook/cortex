# PRD：Phase B — 工作流优先壳

## Goal

把一级导航从「任务 / 日历 / 习惯」模块壳，换成「今天 / 收集箱 / 下一步 / 项目」工作流壳；日历与习惯降为工具。

## Dependencies（写在正文，不靠目录树）

- **硬依赖** Phase A（`09-19-para-semantics-clarify`）**已合并或可本地基于其分支**：否则换壳后「今天/收集箱」标签与真实语义不一致。
- **遵循**父任务 `design.md` 导航表与 Web Guidelines 轻选中语言。
- **不修改** Phase A 已锁定的过滤器合同（除非发现壳层 bug，回 Phase A 修）。

## Requirements

- R1. 主导航：今天（默认）/ 收集箱 / 下一步 / 项目
- R2. 工具区：日历、摘要、搜索、设置；去掉并列「习惯」轨（习惯入口进工具或今天底栏）
- R3. 迷你月历：默认不常驻侧栏底（设置可开或仅日历页内）
- R4. 日历右栏「安排任务」→「未排期下一步」文案与数据源对齐下一步∩无日期
- R5. 深链 URL 覆盖新导航；旧 `#/smart/*` / `#/calendar/*` 兼容或重定向
- R6. 焦点 / hover / 空态符合 Web Interface Guidelines（墨纸、细选中）

## Acceptance

- [ ] AC1. 冷启动默认「今天」，无模块左轨三选一身份
- [ ] AC2. 从工具进入月历，拖拽改期仍写回同一任务且保持已处理
- [ ] AC3. 收集箱 >0 时侧栏强调；空态文案指向处理/排期
- [ ] AC4. `pnpm test` + `tsc` 通过；手跑父 PRD 验收故事 5（工具日历）

## Out of scope

- `processed` 语义与处理模式（必须已由 Phase A 完成）
- 领域 / 资料 / 协作

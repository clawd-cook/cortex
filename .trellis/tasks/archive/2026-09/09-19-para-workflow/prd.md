# PARA 工作流：项目与下一步关联

## Goal

让 Cortex 走通「抓住 → 处理 → 今天执行」，并且项目和下一步连在一起。新进来的事有空就做完，没空进收集箱；处理收集箱时给条目找去处或定日期；今天只显示今天要动手的下一步；项目是有结束线的盒子，盒子里才是可执行的下一步。

本任务只做第一刀闭环，不是 `PRD-cortex-para.md` 的完整 V2.0。

## Background

V1 已有收集箱、今天、明天、普通清单、标签、三栏详情、月历。任务一张表：`listId === null` 即收集箱；「今天」是日期落在当天的未完成工作任务。见 `src/lib/filters.ts`、`src/types.ts`。

清单是平级桶，没有项目容器。侧栏空态引导建「项目清单」和「下一步行动池」。见 `src/components/Shell.tsx:377`。第一用户的真实用法里，项目清单是结果（WIP/DONE 需求条），下一步行动池是动作，两者没有归属。

「今天」按来源清单分组，收集箱条目会和两个清单并列出现。`src/lib/filters.test.ts` 把该行为钉死了。从「今天」添加会写入收集箱且带今天日期，见 `src/components/TaskPane.tsx:154-174`，因此未处理项可以同时出现在收集箱和今天。删除清单会把任务 `listId` 打回 `null`，见 `src/lib/storage/web.ts` 与 `src-tauri/src/db.rs`。

这些行为本任务都要改。不考虑 V1 旧快照兼容。

## Decisions

- D1. 离开收集箱有三条路，走任意一条即离开：① 现在做完；② 挂到已有项目，或把这条变成一个新项目；③ 设日期，成为独立下一步。收集箱只留还没走这三条路的未完成条目。没日期但已挂项目的，出现在该项目和「下一步」，不进今天。
- D2. 第一刀只做每天能用的闭环。处理收集箱复用现有列表 + 详情，不新做卡片流。不做勾完追问、等待中、领域、归档、迁移向导。
- D3. 「变成项目」：原标题成为项目名；原收集项不再作为待办保留。可以立刻写第一条下一步，也可以跳过；跳过后该项目显示「没有下一步」。
- D4. 不考虑旧数据兼容。不保证 V1 本地快照升级后仍能打开。
- D5. 第一刀没有普通清单。侧栏只有智能清单（今天 / 收集箱 / 下一步 / 明天）和项目。横切分类用标签。
- D6. 项目还有未完成下一步时不能删除。先做完、扔掉，或挂到别的项目。

## Requirements

- R1. 新任务可以「现在做」（当场完成）或「放进收集箱」。收集时不强制选择项目。
- R2. 收集箱只放还没走 D1 三条路的未完成条目。详情里可以：挂到已有项目、变成新项目（D3）、设日期成为独立下一步、扔掉。
- R3. 「今天」是过滤器。只显示已离开收集箱、且日期落在今天的可执行下一步。从「今天」添加 = D1 第③路：独立下一步，日期=今天，不进收集箱。今天列表按项目分组，独立下一步落在「独立」组。
- R4. 项目是有结束线的容器。从项目页添加的任务默认属于该项目（已离开收集箱，日期可选）。独立下一步靠设日期离开收集箱。
- R5. 「下一步」是智能清单：已离开收集箱、未完成、可动手。进行中且零下一步的项目有可见提示。
- R6. 一件事只存一次：列表、今天、日历读同一条任务。月历拖拽改期、完成态、本地写入在关应用后仍在。
- R7. 侧栏可新建 / 打开 / 删除项目。没有普通清单入口。空态引导建项目。删除受 D6 约束。
- R8. 详情里「所属」改为项目：可选某个项目，或「无项目」。无项目且无日期 = 收集箱；无项目且有日期 = 独立下一步。

## Out of Scope

- 普通清单作为与项目并列的平级桶
- 领域、资料库、双向链接、笔记软件
- 专门的收集箱处理模式（卡片流 / 处理快捷键仪式）
- 勾完下一步后追问「下一条是什么」
- 等待中（等人 / 等 CI）
- V1 本地数据迁移 / 旧快照兼容、归档区
- 自动从 Slack / 邮件扫入收集箱
- AI 自动拆项目
- 系统通知、番茄、RRULE、CalDAV（GitHub `#21`–`#27`）
- 多人协作

## Acceptance Criteria

- [ ] AC1. 快捷添加可以选择现在做完，完成后收集箱计数不增加。
- [ ] AC2. 在收集箱详情里可以把一条任务挂到已有项目、变成新项目、设日期成为独立下一步、或扔掉；处理后该条离开收集箱。变成项目时标题变为项目名，原收集项不再留在待办；可立刻写第一步或跳过。收集箱可以为 0。
- [ ] AC3. 「今天」只出现已离开收集箱且日期为今天的下一步，按项目分组。未走 D1 的收集项不出现在今天。从今天添加的任务立刻出现在今天，且收集箱计数不增加。
- [ ] AC4. 打开一个进行中的项目，能看到并新增属于它的下一步；从「下一步」智能清单能回到所属项目。
- [ ] AC5. 进行中且零下一步的项目有可见提示。
- [ ] AC6. 关应用再开，本任务写入的项目归属仍在。月历拖拽改期仍然成立。不验收 V1 旧快照能否打开。
- [ ] AC7. 侧栏能新建 / 打开 / 删除项目；没有「普通清单」入口。空态引导建项目。
- [ ] AC8. 项目仍有未完成下一步时，删除被拒绝并说明原因；清空或移走后可以删除。
